# B2Cプレミアムの価格を決めるための材料（P1-7 の前提）

**作成**: 2026-09-04
**対象**: `docs/HUMAN_TASKS.md` P1-7（RevenueCat）／P2-14（特商法の「販売価格」）
**判断が要るもの**: **B2Cプレミアムの月額だけ**です。他は決まっています。

---

## 1. いま決まっているもの／いないもの

コードを読んで確認しました。

| プラン | 月額 | 出所 |
|---|---|---|
| B2B スタンダード（店舗） | **3,980円** | `lib/models/shop.dart:30` |
| B2B プレミアム（店舗） | **9,800円** | `shop.dart:31` |
| B2B エンタープライズ（店舗） | **14,800円** | `shop.dart:32` |
| fleet フリート（5〜20台） | **4,980円** | `lib/models/fleet_plan.dart:19` |
| fleet ビジネス（21〜50台） | **9,800円** | `fleet_plan.dart:23` |
| **B2C プレミアム（一般ユーザー）** | **未定** | **コードのどこにも価格がありません** |

`plan_screen.dart` は機能の比較表を出すだけで、**金額を1円も表示していません**。
RevenueCat の entitlement ID（`btoc_premium`）は定義済みです
（`revenue_cat_service.dart:74`）。

**特商法の「販売価格」欄が埋まらない理由がこれです。**

## 2. B2Cプレミアムで何が変わるか

`UserPlanLimits.forPlan`（`lib/models/user_plan.dart:42-67`）の差分です。

| 項目 | 無料 | プレミアム |
|---|---|---|
| 登録できる車両 | 3台 | 無制限 |
| 工場への問い合わせ | 月3件 | 無制限 |
| ドライブログの保存 | 30日 | 無期限 |
| 愛車カルテのPDF出力 | — | ○ |
| 整備履歴を工場に共有 | — | 無制限 |
| 同車種の統計（コミュニティトレンド） | — | ○ |
| AIによる整備傾向の分析 | — | ○ |
| FAQで工場からの回答を受ける | — | ○ |

**「3台まで」「月3件まで」「30日まで」が、無料で使い続けたときに当たる壁**です。

## 3. 市場の相場

### 個人向けの車両管理アプリは、ほぼ無料です

Drivvo（給油・整備・費用の記録）をはじめ、個人向けのこの種のアプリは**基本無料**で、
課金するとクラウド保存や複数端末の同期が付く、という形が主流でした。

**つまり「記録できること」自体には課金しにくい**市場です。TrustCar の
プレミアムが売っているのは、記録機能ではなく**工場とのつながり（無制限の
問い合わせ・履歴共有・FAQ回答）と、蓄積したデータの活用（PDF・統計・AI分析）**
なので、そこを前面に出せるかが分かれ目になります。

### 日本のアプリ内課金の価格帯

- 心理的に受け入れられやすいのは**月額500〜1,500円**
- **2,000円を超えると成約率が急に落ちる**
- 無料トライアルからの転換率は7日間で iOS 20.4% / Android 9.7%
- ストア手数料は**初年度30%**、13か月目以降は15%

## 4. 価格の候補

**決めるのは社長です。** 判断しやすいように3案だけ置きます。

| 案 | 月額 | 年額（2か月分お得の場合） | 考え方 |
|---|---|---|---|
| A | **480円** | 4,800円 | 相場の下限。無料アプリが多い市場で「試しに」を取りにいく。手数料30%を引くと手取り336円 |
| B | **980円** | 9,800円 | 相場の中心。B2Bスタンダード（3,980円）の1/4で、価格表として説明しやすい。手取り686円 |
| C | **1,480円** | 14,800円 | 上限寄り。台数無制限とAI分析に価値を置く。**個人向けとしては強気**で、無料アプリとの比較で説明が要る |

**判断のポイント**:

- 手数料が引かれるので、**表示価格の70%が初年度の手取り**です
- 年額を作ると解約率は下がりますが、**特商法の表示項目が増えます**（年額の
  価格・更新時期を併記）
- **無料トライアル**を付けるかも決める必要があります（付けるなら期間も）

## 5. 決まったら何をするか

1. `docs/HUMAN_TASKS.md` P1-7 の手順で RevenueCat に商品を作る
2. App Store Connect / Google Play Console でサブスクリプション商品を作成
3. **`web/tokushoho.html` と `docs/web/tokushoho.html` の「販売価格」欄を埋める**
   （**B2C だけでなく B2B の店舗プランも書く必要があります**。どちらも
   アプリ内課金で売るため）
4. `plan_screen.dart` に金額を出すかどうかを決める（現在は機能比較のみ。
   RevenueCat から取った価格を出すのが、ストアの表示と食い違わない形です）

**AI 側でできるのは 3 と 4 です。** 価格が決まったら言ってください。
