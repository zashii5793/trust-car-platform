## 1. 車検証OCR — 最優先

`lib/services/vehicle_certificate_ocr_service.dart`。
車両登録画面（`vehicle_registration_screen.dart:163`）の「スキャン」から。

### 1-1. まず満了日を見てください

**2026-09-03 に、元号の変換バグを直しました。** ML Kit がラベルと値を別の行で
返すと、**令和7年が1995年（30年前）になっていた**バグです。満了日が過去になると、
車検の案内が全部「切れている」と出ます。

修正済みですが、**実物で確かめるべき最初の項目**です。

- [ ] 満了日が**正しい西暦**で入る（1990年代になっていないか）
- [ ] 初度登録年が正しい西暦で入る
- [ ] 令和・平成の両方の車検証で確認できればなお良い

### 1-2. 項目ごとの読み取り

旧様式A4を、明るい室内・真上から撮影した場合。

| 項目 | 結果 | 備考 |
|---|---|---|
| 登録番号（ナンバー） | ☐ 正 ☐ 誤 ☐ 空 | |
| 車台番号 | ☐ 正 ☐ 誤 ☐ 空 | **プレフィックスが5文字（`ZVW30W-` 等）だと途中までしか取れない既知の制限** |
| 型式 | ☐ 正 ☐ 誤 ☐ 空 | **ハイフン必須。旧様式のハイフン無し型式は取れません** |
| メーカー・車種 | ☐ 正 ☐ 誤 ☐ 空 | 40社の固定リストで分割 |
| 初度登録年 | ☐ 正 ☐ 誤 ☐ 空 | 1-1 参照 |
| 満了日 | ☐ 正 ☐ 誤 ☐ 空 | 1-1 参照 |
| 所有者氏名・住所 | ☐ 正 ☐ 誤 ☐ 空 | |
| 総排気量 | ☐ 正 ☐ 誤 ☐ 空 | **単位なしの数字も拾うため、同じ行の別の数字を誤取得しやすい** |
| 燃料の種類 | ☐ 正 ☐ 誤 ☐ 空 | 7語の固定リスト |
| 色 | ☐ 正 ☐ 誤 ☐ 空 | **ラベルと値が別行だと取れません**（この項目だけ次行を見ていない） |
| 乗車定員 | ☐ 正 ☐ 誤 ☐ 空 | |
| 車両重量・総重量 | ☐ 正 ☐ 誤 ☐ 空 | 単位なしでも拾う |

### 1-3. 撮影条件を変えて劣化を見る

**画像の前処理を一切していません**（クロップ・傾き補正・二値化なし）。
撮影条件がそのまま精度に効きます。

- [ ] 蛍光灯の**反射**が入る角度で撮る → どの項目から落ちるか
- [ ] **斜め**（30度くらい）から撮る
- [ ] **折れ目**がある状態で撮る
- [ ] **暗い場所**で撮る（フラッシュあり／なし）
- [ ] ガイド枠からはみ出した状態で撮る（**枠でクロップしていないので背景も渡ります**）

### 1-4. 電子車検証

2023年からの A6 ICカード様式は、**所有者情報が IC タグ側にあり、印字面には
ありません**。OCR では取れない仕様です。

- [ ] 電子車検証（カード）をスキャンしたときの挙動を見る
- [ ] **A4「記録事項」シート**ならどこまで取れるか
- [ ] → カード様式のユーザーに何を案内すべきか決める

### 1-5. 解像度

カメラは `ResolutionPreset.high`（多くの端末で **1280×720**）です
（`document_scanner_screen.dart:110`）。

- [ ] 720p で**車台番号・型式の小さな印字**が読めているか
- [ ] 読めないなら `veryHigh` / `max` への変更を検討（**精度に最も効きそうな箇所**）

| 項目 | 結果 | 備考 |
|---|---|---|
| 合計金額 | ☐ 正 ☐ 誤 ☐ 空 | 「合計」を含む**最後の行**が勝つ |

| 明細（items） | ☐ 取れた ☐ 空 | **品名と金額が同じ行にないと1件も取れません** |

- [ ] **ディーラーの表形式請求書**で明細が取れるか（品名列と金額列が別ブロックに

- [ ] 明細が空のとき、整備内容の説明文も空になるが、それで困らないか

- [ ] 手書きの補足がある請求書

## 3. OCR が失敗したときの導線

- [ ] 車検証: 読み取れないと「下のフォームから手動でも入力できます」と出る → **出るか**
- [ ] 請求書: **こちらには手入力の案内がありません**。エラーだけ出て終わる → 使う人が困らないか
- [ ] 請求書で例外が起きたとき、**画面に生の例外文字列が出ないか**
      （`invoice_ocr_service.dart:184-188` は `'OCR処理中にエラーが発生しました: $e'`。
      車検証側は固定文言にしてあり、**非対称**。要修正候補）

## 4. カメラまわりの挙動

- [ ] **2回続けてスキャン**できる（1回目の後にサービスを閉じているため、
      2回目で再生成されるかを確認する）

      false に戻していないため、破棄済みコントローラを参照する可能性）

- [ ] Android 実機で初回に**権限ダイアログが日本語で出る**

- [ ] フラッシュの3段トグル（auto → torch → off）が効く
- [ ] ギャラリーから選んだ画像でも読める

## 結果の記録

問題が出たら、次を控えておくと直すのが早くなります。

- どの項目が、どう間違ったか（期待値と実際の値）
- 撮影条件（明るさ・角度・距離・フラッシュ）
- 端末とOSのバージョン
- 可能なら**その画像**（車検証は個人情報なので取り扱いに注意。共有せず手元に）
