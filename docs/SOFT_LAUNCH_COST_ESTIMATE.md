## 4. いちばん大きいリスク: AI費用に上限が無い

**現在の制限は「1人1日20回」だけで、全体の上限がどこにもありません。**

30人が毎日上限まで使い、かつ履歴を最大まで積んだ場合の理論値です。

```
 回数   30人 × 20回 × 30日 = 18,000回 / 月
 入力   18,000 × 10,000トークン = 180M × $1.00 = $180
 出力   18,000 ×  1,024トークン =  18M × $5.00 =  $92
 合計                                            $272 ≈ ¥41,000 / 月
```

**通常利用（¥160）の約256倍です。** 30人でこの幅があります。

一般展開（1,000人）では、同じ計算で理論上限が **月 ¥1,360,000** になります。

### 打つべき手（順番に）

```
 1  Anthropic Console で、組織またはワークスペースの使用上限を設定する
 2  Google Cloud で予算アラートを設定する（Firebase 側の暴走も同時に検知できる）
 3  askCarAi に「全体で1日◯回」の上限を足す（いまは1人あたりの上限しかない）
 4  履歴を20件から5件程度に減らす（入力トークンが4分の1になる）
```

**1と2は今日できます。** 3と4はコードの変更なので、実装を依頼してください。
4は体感品質に影響するので、先に1と2を入れてから判断するのが安全です。

## 5. 拡大したときの費用

| 費目 | 30人 | 100人 | 1,000人 |
|---|---|---|---|
| Firestore | ¥0 | ¥0 | ¥0〜2,000 |
| Storage | ¥0 | ¥0 | 約 ¥1,000 |
| Functions | ¥0 | ¥0 | ¥0 |
| Claude API（通常利用） | ¥160 | ¥530 | 約 ¥3,000 |
| Google Maps | ¥0 | ¥0 | ¥0〜3,000 |
| Apple 年会費の月割 | ¥1,250 | ¥1,250 | ¥1,250 |
| **月額合計** | **約 ¥1,400** | **約 ¥1,800** | **約 ¥8,000〜10,000** |

### 最初にぶつかる壁は Firestore の読み取り

```
 1人あたり50回 / 日 × 1,000人 = 50,000回 / 日 = 無料枠のちょうど上限
```

**1,000人が、無料枠の境界です。** ここを超えると読み取りに課金が始まります。
超える前に、旧試算の「読み取り最適化（オンメモリキャッシュ）」を入れると、
無料枠のまま 1,400人程度まで伸ばせます。

### Storage は累積する

保存容量は毎月積み上がります。1,000人なら月2.5GBずつ増えるので、
**2か月で無料枠の5GBを超えます。** 画像の保持期間を決めておく必要があります。

## 6. 旧試算の訂正（Claude API の単価）

同じ利用量の仮定（1人あたり月 入力10K・出力2Kトークン）で引き直すとこうなります。

|---|---|---|
| 1,000 | $2.8 | **$20** |
| 10,000 | $28 | **$200** |
| 100,000 | $280 | **$2,000** |

月次合計への影響です。

| MAU | 旧試算 | 訂正後 |

| 1,000 | ¥1,560 | 約 ¥4,100 |
| 10,000 | ¥10,650 | 約 ¥36,500 |

**10万MAU では月36万円の差になります。** 事業計画に使う場合は訂正後の数字を
使ってください。

## 7. ソフトローンチの進め方（ストア審査を通さずに配る）

**一部のユーザに配るだけなら、App Store と Google Play の審査は不要です。**

| 経路 | 人数 | 審査 | 配り方 |
|---|---|---|---|
| TestFlight 内部テスト | 100人まで | **不要**（アップロード後すぐ） | App Store Connect にユーザを追加 |
| TestFlight 外部テスト | 10,000人まで | Beta App Review（通常1〜2日） | メール招待または公開リンク |
| Google Play 内部テスト | 100人 / リスト | 軽い（要確認） | メールアドレスのリスト |

タカヤの一部ユーザが100人以内なら、**TestFlight 内部テストで審査ゼロで配れます。**
これにより `HUMAN_TASKS.md` の P3（審査申請2件・各2〜3時間＋審査3〜7営業日）を
一般展開まで後回しにできます。

### それでも必要なもの

審査を回避しても、次は避けられません。

```
 P0-1  Android のリリース署名     内部テストでも署名済みAABが要る
 P0-2  Firestore ルールの反映     未反映だと読み書きが全部弾かれる
 P0-4  ログイン方式の本番設定     メール / Google / Apple
 P1-5  iOS の App ID・証明書      TestFlight にも必要
 P1-8  設定ファイルの配置         google-services.json など
 P1-9  実機テスト                 OCRの実画像精度は完全に未検証
```

**P0-3（地図APIキー）は後回しにできます。** 未設定でも距離順リストに
フォールバックする作りになっているためです。
