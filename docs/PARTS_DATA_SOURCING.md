# 正規パーツデータの入手先調査（2026-08-25）

**きっかけ**: 「パーツデータも正規のパーツがないから、テストとしては質が悪くなる。
実際のパーツデータを取得する必要がある」（2026-08-25）

**現状**: `scripts/seed_parts.js` の冒頭にこう書いてある。

```
⚠️ 商品名・ブランド名・型番はすべて架空です。実在のメーカー名は使っていません。
```

300件のパーツ出品は、品番も適合車種も作り物。**「このパーツは自分の車に合うのか」
という、パーツ機能の中心にある問いが検証できない。**

---

## 1. 結論

| 選択肢 | 費用 | 期間 | テストに使えるか |
|---|---|---|---|
| A. 商用の部品検索DBを契約する | 要見積（月額想定） | 問い合わせ〜契約で数週間 | **使える。本命** |
| B. メーカー適合表を1品目だけ手で写す | 0円 | 1〜2日 | **使える。今週の暫定解** |
| C. 一括ダウンロード / 公開API | — | — | **無い**（下記2参照） |

**推奨**: 来週のテストには B。並行して A の問い合わせを始める。

Bを推す理由は、パーツ機能で確かめたいのは「品数」ではなく
**「自分の車に合う／合わないが正しく出るか」**だから。1品目でも実データなら検証できる。
逆に架空データが300件あっても、そこは一生確かめられない。

---

## 2. 一括ダウンロードや公開APIは存在しない

各社とも「車種を選ぶ → 品番が出る」という**検索フォーム**の形でしか出していない。
データそのものを配る窓口は見つからなかった。

| 提供元 | 形 | 一括取得 |
|---|---|---|
| [DENSO スパークプラグ 品番検索](https://am.denso.com/plug/model-search/) | Web検索フォーム | 記載なし |
| [DENSO 他社品番対照表](https://am.denso.com/plug/cross-reference/) | Web検索フォーム | 記載なし |
| [NGK スパークプラグ適応品番検索](https://www.ngk-sparkplugs.jp/ngk/sparkplugs/search/vehicle_type/) | Web検索フォーム（登録不要） | 記載なし |
| [NGK 品番一覧表](https://www.ngk-sparkplugs.jp/ngk/sparkplugs/search/number_list/) | 一覧ページ | 記載なし |

NGKは適合情報を載せたアプリも配布しているが、いずれも
**「人が引くための窓口」であって、データ提供ではない。**

> **やってはいけないこと**: 検索フォームを機械的に叩いて集めるのは、各社の
> 利用規約に反する可能性が高い。**やらない。** 実データが要るなら、
> 下の商用DBを契約するか、手で写す。

## 3. 商用の部品検索データベース（本命）

事業者向けに、純正品番と優良部品の品番を横断で引けるサービスが複数ある。

### 3-1. プロモV8 for NET（株式会社システムプロモート）

- 対応メーカー **約230社**、**約700品目**
- 純正品番だけでなく、**優良部品メーカーの品番も横並びで確認できる**
- 類別番号・型式番号から引ける（TrustCar は車検証OCRで型式を取れるので相性が良い）
- クラウド提供、データは随時更新

**未確認（要問い合わせ）**: API連携の可否 / データ提供の可否 / 料金体系。
ページには一切書かれておらず、問い合わせフォームか電話（0263-58-8836）のみ。

出典: [使い方と品目・メーカーの一覧](https://www.spm-net.co.jp/column/list-autoparts-searchsystem/) /
[株式会社システムプロモート](https://www.spm-net.co.jp/)

### 3-2. ARGOS AIP

- **VIN（車台番号）を入力するだけ**で、純正部品（OEM）と汎用部品（OES）が引ける
- TrustCar は車台番号を持っているので、そのまま渡せる形

出典: [ARGOS AIP](https://argos2020.jp/service3/)

### 3-3. テクタス 自動車部品検索システム

- アセンブリNo.検索 / メーカ・車種検索 / 規格検索
- **互換パーツの検索**が売り

出典: [株式会社テクタス](https://www.tectas.co.jp/products/case/vehicle_parts_search/)

### 問い合わせのときに必ず聞くこと

1. **アプリに組み込めるか**（画面提供だけか、API・データ提供があるか）
2. **エンドユーザーに見せてよいか**（整備事業者の社内利用限定ではないか）
3. 料金体系（月額 / 従量 / 初期費用）
4. 更新頻度と、こちら側でのキャッシュ可否
5. 契約前に評価用データをもらえるか

**2 は特に重要。** TrustCar は一般ユーザーが使うアプリで、
整備工場の社内システムではない。ここで弾かれると A 案が丸ごと消える。

## 4. 今週の暫定解（B案）の具体

**1品目だけ、実在の適合表から手で写す。** 候補はスパークプラグ。

- 適合表が公開されていて確認しやすい
- 車種で品番が変わる（＝適合判定を検証できる）
- 交換周期があり、TrustCar の整備記録と自然に繋がる

**やり方**:

1. ペルソナが持っている車種（プリウス / N-BOX / ハイエース / エルフ / ハイゼットトラック など）
   に絞って、NGK と DENSO の適合表から品番を引く
2. `scripts/seed_parts_real.js` として **架空データとは別ファイル**で投入する
3. 出典と取得日をデータに残す（`source`, `sourceCheckedAt`）
4. **合わない車種の組み合わせも入れる**。適合フィルターが効いているか、
   見分けられるようにするため

**注意**: 品番そのものは事実の表記なので載せられるが、適合表を丸ごと写して
再配布するのは別の話。**必要な車種分だけに絞ること。**

## 5. 関連して見つけたもの — 電子車検証の閲覧API（国土交通省）

パーツとは別件だが、TrustCar に直接効くので記録しておく。

車検証を扱う事業者向けに、**車検証情報をインターネット経由で取得するAPI**が
国土交通省から提供されている。想定利用者に整備事業者・運送事業者・保険会社が
挙げられている。取得できるのは「閲覧アプリでダウンロードできる取込みファイルと
同様に、すべての車検証情報」。

**申請手順**: 利用規約の確認 → API利用申請書をメールで提出 → 承認後にID/PW発行
→ 仕様書ダウンロード → アクセスキー発行 → サービス開始を連絡

**費用**: ページに記載なし。

出典: [車検証閲覧API｜事業者の方へ](https://www.denshishakensho-portal.mlit.go.jp/business/api/)

**なぜ重要か**: いま TrustCar は車検証を**カメラでOCR**している。読み取り精度は
テストの最重要確認項目に挙げているくらい不確かで、Web版では機能そのものが動かない。
電子車検証の情報を正規の経路で取れるなら、**OCRの精度問題が丸ごと消える。**

ただし「事業者向け」の定義に TrustCar が当てはまるかは要確認。
まず利用規約を読むところから。
