利用規約

最終更新日: 2026年8月9日

第1条（適用）

本利用規約（以下「本規約」）は、TrustCar（以下「当サービス」）の利用条件を定めるものです。ユーザーは本規約に同意のうえ、当サービスをご利用ください。

第2条（利用登録）

  1. 利用希望者は本規約に同意し、当サービス所定の方法により利用登録を申請します。
  2. 当サービスは、利用登録申請者に以下の事由があると判断した場合、登録を拒否できます。
    • 虚偽の情報による申請
    • 過去に本規約違反により登録を取り消されたことがある場合
    • その他、当サービスが不適切と判断した場合

第3条（未成年者の利用）

  1. 13歳未満の方は本サービスを利用できません。
  2. 18歳未満の方が利用する場合は、あらかじめ親権者その他の法定代理人の同意を得たうえで利用登録を行ってください。
  3. 18歳未満の方が有料プランをお申し込みになる場合は、お申し込みごとに法定代理人の同意が必要です。同意なく行われたお申し込みについては、当サービスは取り消し、または利用登録を抹消することがあります。
  4. 未成年者が法定代理人の同意を得ずに利用したことにより生じた損害について、当サービスは責任を負いません。ただし当サービスに故意または重大な過失がある場合はこの限りではありません。

第4条（アカウント管理）

  1. ユーザーはログイン情報（メールアドレス・パスワード）を自己責任で管理してください。
  2. アカウントの第三者への譲渡・貸与・共有は禁止します。
  3. 不正利用を発見した場合は速やかに当サービスにご連絡ください。

第5条（禁止事項）

ユーザーは以下の行為をしてはなりません。

  1. 法令または公序良俗に違反する行為
  2. 当サービス・他のユーザー・第三者の権利・利益を侵害する行為
  3. 虚偽の情報を登録・投稿する行為
  4. スパム・迷惑行為・嫌がらせ行為
  5. 当サービスのシステムへの不正アクセス・改ざん行為
  6. 商業目的の無断広告・宣伝行為
  7. その他、当サービスが不適切と判断する行為

第6条（投稿コンテンツ）

  1. ユーザーが投稿したコンテンツの著作権はユーザーに帰属します。
  2. ユーザーは当サービスに対し、コンテンツを無償で利用する権利を許諾します。
  3. 以下のコンテンツの投稿は禁止します。
    • 第三者の著作権・肖像権・プライバシーを侵害するもの
    • 差別的・暴力的・性的なもの
    • 虚偽・誇大な内容を含むもの
    • スパム・広告目的のもの
  4. 当サービスは、規約違反のコンテンツを予告なく削除できます。

第7条（位置情報の利用）

  1. ドライブログ機能の利用にはGPS位置情報の取得許可が必要です。
  2. 位置情報は、ドライブログの記録・表示、近隣の整備工場の検索、走行距離に基づく整備時期の提案に利用します。
  3. 位置情報は、記録中にアプリを利用している間のみ取得します。バックグラウンドでの取得は行いません。
  4. 位置情報の利用はデバイス設定からいつでも停止できます。
  5. ドライブログは初期設定では非公開です。お客様が明示的に公開設定を選択した場合に限り、本サービスの他のユーザーに公開されます。
  6. 公開する場合、経路の始点・終点から半径500m以内の位置情報を除去し、出発地・到着地の住所は市区町村までに丸めて表示します。
  7. 前項の処理は自宅等の所在地の特定を困難にすることを目的とするもので、完全な匿名化を保証するものではありません。複数の公開されたドライブログを組み合わせること等により、行動範囲が推測される可能性があります。この点をご理解のうえ公開設定をお選びください。
  8. 公開を取り消しても、公開されていた期間中に第三者が取得・保存した情報について、当社はその削除または回収を保証することができません。
  9. 位置情報を広告・マーケティング目的で利用せず、第三者に販売しません。

第8条（サービスの変更・中断・終了）

  1. 当サービスは、ユーザーへの事前通知なしにサービス内容を変更・追加・削除できます。
  2. システムメンテナンス・障害等によりサービスを一時中断することがあります。
  3. サービス終了の際は、30日前にアプリ内またはメールで通知します。

第10条（AIによる提案・生成内容）

  1. 当サービスは、整備時期の提案、費用の目安、質問への回答等をAIにより生成します。
  2. AIが生成した内容は参考情報であり、当サービスはその正確性・完全性・特定目的への適合性を保証しません。
  3. AIの提案に従ったこと、または従わなかったことにより生じた損害について、当サービスは責任を負いません。
  4. 車両の安全に関わる判断は、必ず認証工場・指定工場等の専門家にご確認ください。
  5. AIの生成には、ユーザーが登録した車両情報・整備記録を利用します。入力内容は第三者の生成AIサービスに送信される場合があります。

  1. 当サービスは一部の機能を有料プランとして提供します。プランの名称・内容・対価・契約期間は、本サービス上および「特定商取引法に基づく表示」に定めるところによります。

  8. 対価を改定する場合は、改定後の対価が適用される契約期間の開始日の30日前までに通知します。ご同意いただけない場合は、適用前に解約できます。
