## TrustCar テスト版のご案内

このたびは TrustCar のテストにご協力いただき、ありがとうございます。
クルマの車検・整備の記録をまとめて管理し、点検の時期をお知らせするアプリです。

まだ開発中のため、うまく動かないところが残っています。
**「ここが変」「ここが分かりにくい」を見つけていただくことが、今回のお願いです。**

### 使いはじめかた

#### パソコン・スマホのブラウザで使う場合（かんたん・インストール不要）

1. 次のURLを開いてください
   `https://trust-car-platform.web.app`
2. 「新規登録」からメールアドレスとパスワードを登録してください
3. そのままお使いいただけます

スマホのブラウザでも動きます。ホーム画面に追加すると、アプリのように開けます。

> ブラウザ版では、**カメラで車検証を読み取る機能とプッシュ通知は使えません**。
> この2つを試していただく場合は、下のAndroid版をお使いください。

#### Android スマホにインストールして使う場合（全機能が使えます）

1. お送りしたリンクから `TrustCar-....apk` というファイルをダウンロードします
2. ダウンロードしたファイルをタップします
3. **「提供元不明のアプリ」または「この提供元のアプリを許可」** という確認が出ます。
   表示された画面で許可をオンにしてください
   （Google Play を通さないアプリのため、Android が必ず確認してきます）
4. 「インストール」をタップします
5. ホーム画面の「TrustCar」から起動してください

> テストが終わったら、通常のアプリと同じ手順でアンインストールできます。
> 許可の設定も、あわせて元に戻しておくと安心です。

### 試していただきたいこと

全部やる必要はありません。**気になったところだけで大丈夫です。**

**1. 登録してから、愛車を1台入れてみる**
- 迷わず登録まで進めましたか
- 入力する項目は多すぎませんでしたか

**2. 車検の満了日を入れてみる**
- 車検証のどこを見ればいいか、分かりましたか

**3. 整備の記録を1件つけてみる**
- 直近のオイル交換やタイヤ交換で構いません
- 入力の手間はどうでしたか

**4.（Android版のみ）車検証をカメラで読み取ってみる**
- 実物の車検証を撮影して、正しく読み取れましたか
- 間違って読み取られた項目はどれでしたか
- **今回いちばん知りたいところです**

**5. 近くの整備工場を探してみる**
- 出てきた工場は、行ける範囲にありましたか

### APK の作りかた

開発機に Android SDK が入っていないため、GitHub Actions で作ります。

1. GitHub → Actions → **Test APK** → `Run workflow`
2. 完了後、実行ページ下部の **Artifacts** から `trustcar-test-apk` をダウンロード
3. zip を展開して出てくる `.apk` を配布（保持期間は14日）

署名用の Secret（`ANDROID_KEYSTORE_BASE64` ほか）が未設定の間は **profile ビルド**になります。
release と同じ AOT コンパイルなので体感速度はほぼ同じで、debug 鍵で署名されるため直接インストールできます。
Play の内部テストを使う段階になったら `scripts/create_release_keystore.sh` を実行してください。

### フィードバックの見かた

`feedback` コレクションに入ります。**セキュリティルール上、クライアントからは誰も読めません。**
読めるのは Admin SDK と Firebase Console だけです。

```bash
cd scripts && npm install                                   # 初回のみ
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/serviceAccount.json

node read_feedback.js                    # 未対応を新しい順
node read_feedback.js --type bug         # 不具合報告だけ
node read_feedback.js --since 2026-08-24 # 配布日以降
node read_feedback.js --all              # 対応済みも含める
```

| フィールド | 内容 |
|---|---|
| `type` | `request`（こうしてほしい）/ `bug`（うまく動かない）/ `other` |
| `message` | 本文（2000文字まで） |
| `appVersion` / `platform` | 送信時のビルド。`web` / `android` / `ios` |
| `screen` | 送信元の画面（`profile` / `help`） |
| `contactEmail` | 任意。未入力なら null |
| `status` | `open` 固定で作成される。トリアージ後に運用側で更新 |

### 既知の制約（聞かれたときの答え）

| 指摘されそうなこと | 現状 |
|---|---|
| ブラウザで車検証の読み取りが出てこない | Web は OCR 非対応。`isSupported` で導線ごと隠している |
| プッシュ通知が来ない | APNs/FCM の設定が未完了。ローカル通知のみ動作 |
| 走行記録が途中で止まる | 前面でのみ記録する仕様。記録画面に明記済み |
| 地図が出ない | Maps API キー未設定時は距離順リストにフォールバック |
| パーツの売買が見当たらない | C2C マーケットは意図的に凍結中 |
| iPhone 版はないのか | 準備中。Firebase の iOS アプリ登録と Apple の審査が残っている |
