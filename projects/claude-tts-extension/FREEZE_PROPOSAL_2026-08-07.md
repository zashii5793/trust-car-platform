**凍結しても、止まるものがありません。** 現時点で誰かの業務が
このリポジトリの更新に依存している形跡はありません。

### したがって「凍結」の実質は記録だけです

```
 やること   これ以上ここに工数を割かないと決め、その旨を残す
 やらないこと  削除・アーカイブ・非公開化（いずれも不要かつ不可逆）
```

> **リポジトリの削除や private 化は推奨しません。** public のまま置いておく
> コストはゼロで、再開時の手間だけが増えます。

### 1点だけ注意 — 依存の逆向きがあります

このツールは **Claude Code の Stop Hook 仕様**と
**claude.ai の DOM 構造**に依存しています。

```
 Claude Code の hooks 仕様が変わる    → hooks/ が黙って動かなくなる
 claude.ai の画面構造が変わる         → content.js が黙って動かなくなる
```

**凍結中は、壊れても誰も気づきません。**
これは凍結の理由にはなりませんが、**再開時の前提**として記録しておく価値があります
（「凍結解除時はまず動作確認から」）。
